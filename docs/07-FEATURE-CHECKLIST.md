# Feature Checklist: what was missing & what we add

The full list of what a complete open-world game needs, marked with the phase it lands in. ✅ = already in the plan, ➕ = **newly added** after review.

## Core experience
| Feature | Phase | Status |
|---|---|---|
| Tutorial / onboarding (first 5 minutes teach controls through Mission 1, device-aware prompts) | P5 | ➕ |
| Loading screen with tips & Dhaka jokes, progress bar | P1 | ➕ |
| Main menu, pause menu, settings, credits | P1 | ✅ |
| Checkpoints & mission retry, skip cutscene | P5 | ➕ |
| Autosave + manual save at safehouses | P5/P6 | ✅ |
| Difficulty settings | P7 | ➕ |

| Gym (strength skill) | P7 | ➕ |

| Garage & vehicle mods (colour, horn type, rickshaw art paint, bike exhaust, nitro) | P7 | ➕ |
